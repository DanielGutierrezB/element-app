Política de privacidad

Element es una herramienta personal. Solo la usa su dueño, con sus propias cuentas de Google.

  • Qué datos usa: lee los correos de Gmail de su dueño, con permiso de solo lectura.
  • Dónde quedan: la información se procesa y se guarda solo en el computador del dueño.
  • Con quién se comparte: con nadie. No se venden, no se transfieren a terceros y no se usan para publicidad.
  • Cómo revocar el acceso: desde la configuración de seguridad de la cuenta de Google, en "Apps de terceros con acceso a tu cuenta".

El uso de la información recibida de las API de Google cumple la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Privacy policy

Element is a personal tool used only by its owner with their own Google accounts. It reads the owner's Gmail messages with read-only access. Data is processed and stored only on the owner's computer. It is never sold, shared with third parties or used for advertising. Access can be revoked at any time from the Google Account security settings. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
